# 전결 검색 아키텍처 결정 기록

작성일: 2026-09-09

## 결정

이 앱은 위임전결규정 검색표를 브라우저에 내장하고 결정형 로컬 검색만 제공한다. LLM 호출, 사용자 API 키, 외부 AI SDK, 서버 API 라우트는 사용하지 않는다.

## 이유

- 전결 판단은 규정 원문과 정규화된 표의 근거를 직접 추적해야 한다.
- 생성형 응답의 비용·지연·비결정성·외부 전송을 제거한다.
- 현재 배포 방식이 Next.js 정적 export와 GitHub Pages이므로 서버 없는 구조가 운영에 맞다.
- 규정표에 없는 업무는 추정하지 않고 미등록으로 안내한다.

## 데이터 흐름

```text
CSV 원천
  → scripts/gen-table.mjs
  → lib/tableData.generated.ts
  → lib/table.ts / lib/resolve.ts
  → lib/lookup.ts 로컬 검색·캐시
  → app/page.tsx 결과 모달
```

## 전체 원본 확대 조건

24개 시트를 추가할 때는 시트명, 부서명, 원문 행 번호, 기안·전결 표시, 조건의 원문 근거를 정규화 데이터에 보존한다. 같은 업무명이 여러 부서에 존재하는 경우의 범위 선택 규칙을 먼저 정한다. 검색 결과는 근거 행을 표시하고, 변환 결과의 행 수·누락·중복을 테스트한다.
